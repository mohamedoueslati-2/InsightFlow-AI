# React / Shadcn Admin visual migration

This version keeps the existing InsightFlow behavior and backend contracts unchanged, while applying a light, professional admin-dashboard visual system inspired by shadcn-admin.

Preserved legacy runtime files:
- `validation-ui.js`
- `cleaning-ui.js`
- `dashboard.js`
- `script.js`
- `report-ui.js`

The redesign changes only shell/layout markup that is not part of the application logic plus CSS presentation. Data Formulator and Presenton continue to render as independent full-canvas Docker tools.
